# 생성 모델 계열의 갈래

> 생성형 인공지능의 모델 계열(자기회귀 언어 모델, 생성적 적대 신경망, 확산 모델, 음성 합성, 텍스트-비디오 모델)은 각각 어떤 문제를 풀려고 지금 모양이 되었고, 서로 무엇을 대안으로 밀어냈는가?

## 서론

이 원고는 생성형 인공지능의 여러 계열을 **“무슨 문제를 풀기 위해 그 모양이 되었는가”**와 **“그 과정에서 어떤 대안을 밀어냈는가”**라는 두 축으로 엮어 보여준다. 자기회귀 언어 모델은 다음 토큰 예측을 공용 목표로 삼아 라벨 비용과 태스크별 분절을 줄이고 범용성을 얻었으며, 기존의 규칙 기반 NLP, 통계적 방법, RNN/LSTM, seq2seq의 여러 병목을 넘어서는 방향으로 정착했다. GAN은 “데이터를 잘 맞추는 것”보다 “진짜처럼 보이는가”를 겨루는 방식으로 이미지 생성 문제를 풀기 위해 등장했고, VAE나 재구성 중심 접근이 남긴 저해상도·복원 위주의 한계를 밀어냈다. 이후 확산 모델은 GAN의 불안정성과 모드 붕괴를 피하면서 더 안정적이고 고품질의 생성을 제공하는 쪽으로 올라섰다. [D:생성적 적대 신경망] [D:생성형 인공지능] [D:텍스트-이미지 모델] [D:확산 모델] [D:스테이블 디퓨전]

음성 합성은 자연스러움과 명료성에서 출발해 실시간성, 화자 일관성, 감정 제어로 확장되었고, unit selection과 HMM 기반 합성이 각각의 장점에도 불구하고 신경망 기반 합성에 자리를 내주었다. WaveNet은 보코더/파형 생성 단계를 직접 모델링하는 방향으로 바뀌었고, 최근 계열은 더 작은 데이터로 특정 화자와 스타일을 옮기는 쪽까지 나아갔다. [D:음성 합성] [D:은닉 마르코프 모형] [D:웨이브넷] [D:15.ai]

텍스트-비디오 모델은 텍스트를 프레임과 시간축에 맞춰 일관된 영상으로 바꾸는 문제를 풀기 위해 형성되었고, 정지 이미지를 만드는 텍스트-이미지 모델보다 한 단계 더 나아가 움직임과 연속성을 다룬다. 이때 밀려나는 대안은 텍스트-이미지 자체라기보다 전통적인 CGI 워크플로와 수작업 중심 영상 제작 공정의 일부로 정리된다. [D:텍스트-비디오 모델] [D:텍스트-이미지 모델] [D:컴퓨터 그래픽스] [D:신경 방사장]

## 자기회귀 언어 모델: 다음 토큰 예측이 표준이 되기까지

### 다음 토큰 예측이 공용 목표가 된 이유
자기회귀 언어 모델의 핵심은 앞선 토큰들로부터 다음 토큰을 예측하는 인과적 언어 모델링이며, GPT는 이를 디코더 전용 트랜스포머에서 레이블 없는 텍스트의 사전학습과 과제별 미세조정으로 구현했다. [D:트랜스포머 (기계 학습)] [D:대형 언어 모델] [D:자기 지도 학습]
이 목표는 대규모 말뭉치에서 자기지도 방식으로 학습할 수 있어 라벨링 비용을 줄이고, 그렇게 얻은 표현을 여러 언어 이해·생성 과제에 재사용할 수 있게 했다. [D:대형 언어 모델] [D:자연어 처리] [D:자기 지도 학습]
프롬프트 예시만으로 일시적으로 과제를 맞추는 인컨텍스트 학습이 보고되면서, 하나의 공용 다음 토큰 예측기가 별도 태스크별 모델보다 유리하다는 인식이 강해졌다. [D:프롬프트 엔지니어링]

### 무엇이 밀려났나
전통적 NLP는 수작업 규칙과 사전 조회에 의존했지만, 1980년대 말 이후 기계학습이 도입되면서 규칙 기반 시스템의 비효율성과 확장성 한계가 드러났고, 통계적 방법도 작업별 말뭉치 의존성과 제한된 범용성이라는 한계를 가졌다. [D:자연어 처리]
통계적 방법은 낯선 입력이나 오류가 있는 입력에 더 견고하고 제작 비용도 적었지만, 대규모 데이터와 주석이 필요했고, 전통적 파이프라인의 중간 작업은 신경망 기반 접근이 넓히면서 점차 불필요해졌다. [D:자연어 처리]
2003년의 n-그램 모델은 당시 최고 수준이었지만, 더 긴 문맥을 쓰는 다층 퍼셉트론에 추월당했고, 이후에는 RNN과 LSTM이 순차 데이터를 처리하는 주류가 되었지만 장기 의존성과 기울기 소실 문제가 남았다. [D:자연어 처리] [D:순환 신경망] [D:딥 러닝]
2014년의 seq2seq는 가변 길이 입력과 출력을 직접 다루었지만, 입력 전체를 하나의 고정 길이 벡터에 압축해야 했고, 이 병목을 어텐션이 완화했지만 인코더와 디코더 내부에는 여전히 RNN이 남아 있었다. [D:트랜스포머 (기계 학습)]

### 트랜스포머와 LLM이 바꾼 것
트랜스포머는 순환과 합성곱을 제거하고 셀프 어텐션으로 시퀀스 내 위치들 사이의 관계를 한 번에 계산해, 학습 시 여러 위치를 병렬로 처리할 수 있게 했으며 번역 품질과 학습 시간에서 개선을 보였다. [D:트랜스포머 (기계 학습)]
완전 셀프 어텐션은 모든 위치 쌍의 점수를 계산하므로 계산량이 입력 길이의 제곱에 비례하지만, 그 대신 긴 의존성을 직접 다룰 수 있어 이전 순환계열보다 범용성이 커졌다. [D:트랜스포머 (기계 학습)]
LLM은 수십억 파라미터 규모의 자기지도/반자기지도 텍스트 모델로 자리 잡았고, 2023년 이후에는 프롬프트 기반 문제 해결과 멀티모달 확장이 두드러졌지만 2024년에도 가장 큰 모델들은 여전히 트랜스포머를 기반으로 했다. [D:대형 언어 모델]
프롬프트 예시를 통해 일시적으로 학습하는 인컨텍스트 학습은 모델 규모의 창발적 능력으로 설명되며, 이것이 대형 모델을 단순한 생성기가 아니라 맥락을 읽어 작업을 전환하는 범용 인터페이스로 바꾸는 계기가 됐다. [D:프롬프트 엔지니어링]

### 챗GPT식 대화형 인터페이스가 바꾼 목표
챗GPT는 LLM을 사람과 유사한 응답을 하는 생성형 챗봇으로 패키징했고, 지도학습과 RLHF로 대화형 애플리케이션에 맞게 파인튜닝했다. [D:챗GPT] [D:인간 피드백을 통한 강화 학습]
대화의 각 단계에서 앞선 사용자 발화와 모델 응답이 맥락으로 취급되면서, 목표는 단순한 다음 토큰 예측에서 사용자 지시를 따르고 대화 맥락을 이어 가는 비서형 행동으로 이동했다. [D:챗GPT] [D:프롬프트 엔지니어링]
또한 웹 검색, 앱 활용, 프로그램 실행 같은 도구 접근이 붙으면서, 언어 생성은 독립적 출력이 아니라 작업 실행의 인터페이스가 되었고, 그래서 프롬프트 엔지니어링과 컨텍스트 관리가 중요해졌다. [D:챗GPT] [D:프롬프트 엔지니어링]
다만 LLM은 여전히 환각과 최신성 한계를 남기고, 트랜스포머의 이차적 계산량은 긴 문맥 처리 비용으로 남아 있다. [D:대형 언어 모델] [D:트랜스포머 (기계 학습)]

## 생성적 적대 신경망: 왜 ‘대결 학습’이 필요했나

### 왜 적대적 목적함수였나
GAN은 2014년 이언 굿펠로와 동료들이 제안한 모델로, 생성자와 판별자가 서로 경쟁하는 최소최대 게임으로 학습한다. [D:생성적 적대 신경망]
문서는 굿펠로가 최대 가능도 추정의 어려움을 피하면서도 강력한 생성 모델을 만들 방법을 찾고 있었고, 그 결과 판별자의 진짜/가짜 구분 신호를 학습 신호로 쓰는 구조가 나왔다고 설명한다. [D:생성적 적대 신경망]
즉 GAN은 데이터를 직접 잘 맞추는 우도 최대화보다, “진짜처럼 보이는가”를 겨루는 방식으로 이미지 생성 문제를 풀도록 설계되었다고 볼 수 있다. [D:생성적 적대 신경망]

### GAN이 겨냥한 핵심 문제
GAN이 정면으로 겨냥한 것은 이미지가 흐릿하게 뭉개지는 문제를 줄이면서, 실제 사진처럼 선명하고 현실감 있는 샘플을 만드는 것이었다. [D:생성적 적대 신경망][D:생성형 인공지능]
GAN 문서는 이 구조가 실제 데이터의 통계적 분포와 매우 유사한 데이터를 생성하게 만들며, 특히 컴퓨터 비전에서 사실적인 이미지 생성, 이미지 대 이미지 변환, 초해상화에서 획기적인 성과를 보였다고 적는다. [D:생성적 적대 신경망][D:컴퓨터 비전]
생성형 인공지능 문서도 GAN이 사실적인 이미지 생성의 가능성을 열었다고 정리한다. [D:생성형 인공지능]
딥 러닝 문서는 합성곱 신경망이 영상 분야에서 강하고 적은 매개변수로도 잘 훈련되며, GPU와 대량 데이터가 심층 모델의 확산을 가능하게 했다고 설명하는데, GAN도 이런 컴퓨터 비전 환경 위에서 현실감 있는 이미지 생성에 특화된 흐름으로 자리 잡았다. [D:딥 러닝][D:생성적 적대 신경망]

### VAE·재구성 기반 방법과의 비교
초기 텍스트-이미지 계열의 alignDRAW는 어텐션이 있는 순환 변이형 오토인코더를 확장한 모델이었지만, 생성 결과가 32×32 수준의 저해상도였고 다양성이 낮다고 평가되었다. [D:텍스트-이미지 모델]
같은 문서에서 2016년의 GAN 기반 텍스트-이미지 모델은 “시각적으로 그럴듯한” 이미지를 만들 수 있었지만, 더 다양한 COCO 데이터셋에서는 세부 일관성이 부족했다고 적는다. [D:텍스트-이미지 모델]
생성형 인공지능 문서는 변이형 오토인코더를 데이터를 저차원 잠재 공간에 압축한 뒤 디코더로 복원하는 구조로 설명하므로, GAN과 비교하면 재구성 중심의 접근이었다고 볼 수 있다. [D:생성형 인공지능]
자료에서 확인되는 대비는, VAE/재구성 중심 접근이 표현은 안정적이지만 저해상도·복원 위주 한계를 보인 반면, GAN은 더 현실감 있는 이미지를 내는 쪽에 강했다는 점이다. [D:텍스트-이미지 모델][D:생성형 인공지능][D:생성적 적대 신경망]

### 자기회귀 이미지 모델과의 관계
생성 모델 문서는 자기회귀모형을 생성 모델 계열의 한 갈래로만 제시할 뿐, 이미지 생성에서의 구체적 장단점이나 GAN과의 직접 비교는 적지 않는다. [D:생성 모델]
따라서 이 코퍼스만으로는 자기회귀 이미지 모델이 GAN을 어떤 방식으로 대체했는지까지는 직접 확인되지 않는다. [D:생성 모델]

### GAN의 장단점과 이후의 재부상
GAN의 장점은 선명도와 현실감, 그리고 고차원 이미지 분포에서 그럴듯한 샘플을 뽑는 능력이었지만, 단점은 학습 불안정성, 모드 붕괴, 그리고 사실성과 다양성을 객관적으로 평가하기 어렵다는 점이었다. [D:생성적 적대 신경망]
GAN 문서는 이런 약점을 보완하려고 DCGAN이 합성곱 구조와 배치 정규화로 학습을 안정화했고, WGAN은 바서슈타인 거리를 써서 더 안정적인 그레이디언트를 얻으려 했다고 설명한다. [D:생성적 적대 신경망]
또 StyleGAN은 고해상도 인물 얼굴에서 극도로 사실적인 결과를 내며 GAN의 이미지 사실성을 한 단계 끌어올렸다. [D:생성적 적대 신경망]
그럼에도 생성형 인공지능 문서와 스테이블 디퓨전 문서는 2020년대 들어 확산 모델이 GAN보다 안정적이고 고품질의 이미지 생성을 제공하면서 주류로 부상했다고 정리한다. [D:생성형 인공지능][D:스테이블 디퓨전]
스테이블 디퓨전 문서는 확산 모델이 잠재 확산 구조로 텍스트 조건부 고품질 이미지를 만들고, 계산 효율성까지 확보했다고 설명한다. [D:스테이블 디퓨전]
그래서 GAN이 밀어낸 대안은 주로 VAE와 재구성 중심의 초기 이미지 생성법이었고, 이후 GAN의 불안정성과 모드 붕괴 때문에 확산 계열이 다시 중심으로 올라왔다고 정리할 수 있다. [D:텍스트-이미지 모델][D:생성형 인공지능][D:생성적 적대 신경망]

## 확산 모델: 안정성과 품질을 얻기 위한 점진적 생성

확산 모델은 순방향 확산으로 데이터에 노이즈를 점진적으로 더해 거의 표준 가우시안까지 보낸 뒤, 그 역방향 샘플링을 학습해 다시 데이터 분포로 돌아오게 하는 잠재 변수 생성 문제를 푼다. [D:확산 모델]

DDPM 계열은 각 시점의 노이즈가 섞인 입력 `x_t`와 시간 `t`를 받아 노이즈 `ϵ_θ(x_t,t)`를 예측하게 학습하고, 원 논문은 변분 하한(ELBO)을 사실상 노이즈 예측 MSE로 단순화했다. [D:확산 모델]

점수 기반 공식화에서는 `∇_x log q(x)` 또는 시간/노이즈 조건부 점수를 배우며, 이산 또는 연속 노이즈 스케줄 `β_t`, `σ_t`가 단계별 어닐링을 담당한다. [D:확산 모델]

이 절차는 GAN이 안고 있던 학습 불안정성과 모드 붕괴를 피하려는 선택으로 읽을 수 있다. GAN은 생성자-구분자 min-max 게임이라 구분자가 너무 강해지면 생성자의 그레이디언트가 사라질 수 있고, 생성자가 몇 개의 쉬운 샘플만 반복하는 모드 붕괴가 발생할 수 있다. [D:생성적 적대 신경망]

반면 확산은 “한 번에 속이기”가 아니라 모든 노이즈 수준에서 원본으로 복원하는 문제로 바꾸기 때문에, 적대적 게임보다 안정적인 학습 신호를 준다. 확산 문서는 어닐링을 통해 점진적으로 노이즈를 추가한 다음 점수 함수를 학습하고 다시 역방향 확산을 수행한다고 설명한다. [D:확산 모델][D:생성적 적대 신경망]

샘플링은 `x_T`에서 `x_0`를 한 번에 뽑는 대신 `x_t → x_{t-1}`를 반복하는데, 역과정이 단계별로만 정의되고 중간 상태를 필요로 하기 때문이다. 원래 DDPM은 보통 약 1000단계를 써서 느리지만, DDIM은 단계를 건너뛰어 20단계 안팎에서도 유사한 샘플을 얻을 수 있어 속도와 품질을 절충한다. [D:확산 모델]

텍스트-이미지 영역에서는 초기엔 조건부 GAN이 쓰였지만, 최근에는 확산 모델이 더 인기 있는 옵션이 되었고 Stable Diffusion은 그 전형적인 잠재 확산 모델이다. [D:텍스트-이미지 모델][D:스테이블 디퓨전]

Stable Diffusion은 VAE로 이미지를 잠재공간에 압축한 뒤 그 공간에서 확산을 돌리고, 텍스트 인코더와 교차 주의로 조건을 주며, classifier-free guidance로 프롬프트 일치도를 조절한다. [D:스테이블 디퓨전][D:확산 모델]

이 점이 조건부 생성에서 강점이 되었는데, 분류기 없는 가이던스는 조건 없는 예측과 조건 있는 예측을 섞어 출력이 프롬프트에 더 가깝게 붙도록 만들고, 이미지 생성 품질을 높이기 위해 가이던스 스케일을 조절할 수 있다. [D:확산 모델]

다만 그 대가로 추론 시 단계 수가 늘수록 시간이 길어지고, 실제 훈련도 256개의 A100에서 150,000 GPU 시간을 쓰는 등 계산 비용이 컸다. [D:스테이블 디퓨전]

요약하면 확산 모델은 GAN을 이미지/텍스트 조건부 생성의 주류 선택지 일부에서 밀어냈지만, 더 느린 샘플링과 높은 계산량을 대가로 치렀다. [D:텍스트-이미지 모델][D:스테이블 디퓨전][D:확산 모델]

## 음성 합성: 자연스러운 발화와 실시간성을 향한 계보

음성 합성의 핵심 문제는 처음에는 **자연스러움과 명료성**이었고, 실제 제품과 보조기술 맥락에서는 여기에 **실시간성**, 최근에는 **화자 일관성·감정 제어**가 더해지며 목표가 넓어졌다. [D:음성 합성][D:15.ai]

unit selection 합성은 대규모 녹음 음성 조각을 이어 붙여 가장 자연스러운 출력을 노렸지만, 데이터베이스 구축에 수십 시간 규모의 녹음이 필요하고 강제 정렬·수동 분할이 들어가며, 런타임의 최적 단위 선택도 때때로 부자연스러운 세그먼트를 고르는 한계가 있었다. [D:음성 합성]

HMM 기반의 통계적 파라메트릭 합성은 음성의 스펙트럼, 기본주파수, 길이를 동시에 모델링했지만, 출력이 로봇 같아지기 쉽고 자연스러움에서 연결 합성보다도 불리한 면이 있어 주류 대안으로는 밀려났다. [D:음성 합성][D:은닉 마르코프 모형]

즉 unit selection은 자연스러움은 높지만 무겁고, HMM 기반 합성은 작고 제어 가능하지만 덜 자연스러워서, 둘 다 더 자연스러운 신경망 기반 합성에 자리를 내주었다. [D:음성 합성][D:은닉 마르코프 모형]

WaveNet은 기존 TTS 파이프라인에서 **백엔드 보코더/파형 생성 단계**를 대체한 기술로, 텍스트를 음소와 스펙트럼으로 바꾼 뒤 별도 보코더가 파형을 만드는 방식 대신 **원시 오디오 파형을 직접 모델링**했다. [D:웨이브넷][D:음성 합성]

WaveNet 계열은 구글의 기존 TTS보다 더 나은 음질을 보였지만, 출시 당시에는 계산량이 매우 커서 실제 응용에 쓰기 어려웠고 이후에야 더 빠른 생성이 가능해졌다. [D:웨이브넷]

최근의 음성 합성은 텍스트 정규화, 발음/음소 변환, 운율 조건화, 화자 임베딩, 신경망 보코더를 다시 분해해 조합하는 방향으로 바뀌었고, 15.ai는 다화자 모델과 감정 맥락, ARPABET 직접 입력을 통해 캐릭터 음성 복제와 감정 표현을 함께 다루었다. [D:음성 합성][D:15.ai]

이 흐름은 적은 데이터로도 특정 화자의 목소리와 스타일을 옮기는 쪽으로 이어졌으며, 15.ai는 **15초의 음성 데이터만으로도 감정이 실린 음성을 복제할 수 있다**는 주장을 내세웠고, 보이스버스 사례에서도 같은 플랫폼이 그 짧은 데이터 효율을 전제로 악용될 수 있음이 드러났다. [D:보이스버스 NFT 표절 논란][D:15.ai]

남은 한계는 여전히 데이터 부족 시의 견고성 저하, 자동 운율 제어의 어려움, 성조 언어에서의 오류 가능성, 그리고 서비스별 영어 전용·단어 수 제한 같은 운영 제약이다. [D:음성 합성][D:15.ai]

## 텍스트-비디오 모델: 생성형 비디오가 산업 워크플로를 바꾸는 방식
